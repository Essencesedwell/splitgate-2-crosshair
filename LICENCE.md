## 🧩 About

**Splitgate 2 Crosshair** is a comprehensive overlay for Splitgate 2 featuring custom crosshair editor, dynamic color changer, recoil visualizer, hitmarker enhancer, no-recoil scripts, and crosshair presets.

Based on popular overlays like **Custom Crosshair**, **HudSight**, and **Crosshair X**.

## ✨ Features

### 🎯 Crosshair Customization
- Custom Crosshair Editor — design your own crosshair with adjustable size, gap, thickness, and style
- Dynamic Color Changer — set static or dynamic colors based on game events
- Crosshair Presets — save and load multiple crosshair profiles
- Outline & Dot Options — add outlines or center dots for visibility

### 📊 Visual Feedback
- Recoil Visualizer — see recoil patterns in real-time during shooting
- Hitmarker Enhancer — customize hitmarker sounds and visuals
- Damage Indicator — display damage dealt with floating numbers
- Enemy Outline — optional outline for better target acquisition

### ⚙️ Gameplay Scripts
- No-Recoil Script — compensate for weapon recoil automatically
- Rapid Fire — adjustable fire rate for semi-auto weapons
- Auto-Reload — automatically reload when magazine is empty
- Quick-Switch — instantly switch between weapons
